# AloCsvEditor

Windows 上的轻量现代 CSV 编辑器。绿色免安装，双击即用；自动识别编码不乱码；几万行也流畅；编辑手感接近 Excel。

用 Excel 打开 CSV 会悄悄改数据（`00123` 变成 `123`、长数字变科学计数法），专用 CSV 工具又普遍老旧、收费或有坑——这个工具就是为了解决这些事。

## 使用环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / Windows 11（**仅 64 位**） |
| 运行时依赖 | WebView2 Runtime（Windows 11 与绝大多数 Windows 10 已随系统自带） |
| 安装 | 不需要，单个 exe 绿色免运行 |
| 磁盘占用 | 约 50 MB |

> 不支持 32 位系统、ARM 架构电脑，以及 Windows 8.1 及更早版本。

## 安装依赖

本软件唯一的外部依赖是 **WebView2 Runtime**：

- Windows 11 与绝大多数 Windows 10 已预装，**通常什么都不用做**。
- 若启动时弹出提示"未检测到 WebView2 Runtime"，任选其一即可：
  1. 安装最新版 **Microsoft Edge** 浏览器（自带该运行时）；
  2. 在网上下载安装「**WebView2 Runtime**」（Evergreen 版），然后重新打开本软件。

其余依赖（.NET 运行时等）已全部打包在 exe 内，无需另装。

## 部署说明

1. 取得 `AloCsvEditor.exe`（就一个文件）。
2. 复制到任意可写目录（桌面、`D:\Tools\` 都行），**双击运行**。
3. 常用建议：右键 exe → 发送到 → 桌面快捷方式。
4. 想用双击 CSV 就打开本软件：右键任意 `.csv` → 打开方式 → 选择其他应用 → 找到 `AloCsvEditor.exe` → 勾选"始终使用"。

**卸载**：程序不会往 exe 所在目录写任何文件，直接删掉 exe 即卸载。个人设置存放于 `%AppData%\AloCsvEditor\settings.json`（删除该文件即恢复默认设置）。

## 使用说明

### 打开与保存

| 操作 | 方式 |
|---|---|
| 打开文件 | 工具栏「打开」按钮 / 把文件**拖进窗口** / 把文件路径作为启动参数 / 双击已关联的 csv |
| 保存 | 工具栏「保存」，或 `Ctrl+S`（原编码、原换行符回写） |
| 另存为 | 工具栏「另存为」，或 `Ctrl+Shift+S` |
| 新建空表 | 工具栏「新建」 |
| 未保存提示 | 有未保存修改时标题栏文件名后会出现 `*`；关闭窗口会询问是否保存 |

编码与换行符都会自动识别并原样保留；需要换编码时用工具栏的**格式按钮**（编码/分隔符），切换后会按新格式重新载入当前文件。

### 编辑单元格

- **单击**选中，**双击**（或按 `F2`，或直接**打字**）进入编辑。
- `Enter` 提交并下移，`Shift+Enter` 上移，`Tab` 右移，`Shift+Tab` 左移，`Esc` 取消。
- 编辑中想在单元格里换行：`Alt+Enter`。

### 选区

- 鼠标拖选；`Shift+单击` / `Shift+方向键` 扩展选区；`Ctrl+A` 全选。
- `Ctrl+单击` 可加选多个不连续区域；`Esc` 清除多选。

### 复制 / 粘贴

- `Ctrl+C` 复制、`Ctrl+X` 剪切、`Ctrl+V` 粘贴。
- 与 **Excel 完全互通**：从 Excel 复制一片区域可直接粘进来，这里复制的结果也能直接粘进 Excel。

### 拖动填充（重点功能）

- 选中区域后，按住选区**右下角的小方块**拖动：向下/向右自动填充。
- 自动判断规则：单个数字**复制**（按住 `Ctrl` 拖则**递增**）；`A001`、`第3` 这类**结尾是数字**的文本自动递增且保留位数；多个数字按已有**差值等间隔**延续；其他内容**循环重复**。
- 特别地：按 `Ctrl` 拖动可强制按序列递增填充。
- **双击**填充柄：自动向下填到相邻列数据的末尾。

### 拖动移动

- 按住选区**边框**拖动可移动内容；按住 `Ctrl` 拖动则是复制。

### 增删行列

- 右键**行号**或**列头**，菜单里有插入/删除。
- 快捷键：`Ctrl+I` 下方插入行、`Ctrl+U` 上方插入行、`Ctrl+J` 右侧插入列、`Ctrl+K` 左侧插入列。
- `Delete`：选中**整行**时删整行，选中**整列**时删整列；选一片普通区域时只清空内容（不会误删结构）。

### 排序 / 筛选 / 查找

- **排序**：右键**列头** → 升序 / 降序 / 清除排序。数字按数值大小排，文本按拼音排。
- **筛选**：工具栏"筛选"框输入关键字，右边下拉选择作用列（全部列或指定某列），只显示包含关键字的行；状态栏可一键清除。
- **查找替换**：`Ctrl+F` 打开查找栏，支持上一个/下一个、替换当前/全部、区分大小写、正则表达式。

### 注释行与表头

- **注释行**：在**第一列内容的最前面**加上注释符号（默认 `#` 或 `//`），整行立刻变成一条灰显的注释，**不再按逗号拆列**，整行原样显示、原样保存。把符号去掉，又恢复成正常的多列数据。
- **表头行**：默认自动认"跳过注释后的第一行"为表头（加粗、冻结在顶部、不参与排序）。想改的话，右键那一行的**行号** → "设为表头行"。
- 注释符号可以在「设置」里自定义。

### 界面与设置

- **主题**：工具栏的图标可切换**暗色 / 亮色**。
- **缩放**：按住 `Ctrl` 滚**鼠标滚轮**，只缩放表格内容（界面本身不变）。
- **设置面板**（齿轮图标）：主题、内容缩放、界面字号、默认分隔符、十字高亮、斑马纹、表头开关、表头行、注释标记。
- **关于**：设置面板底部「关于 AloCsvEditor」，可查看版本与作者信息。
